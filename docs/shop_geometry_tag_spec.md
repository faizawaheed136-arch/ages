# Corner Shop Geometry Tag Spec

Agent A — add these tags and attributes to the parts generated by `gen_town.py` in the corner shop block.

## Overview

The fetch-and-bag subsystem reads shop geometry by CollectionService tag, not by part name. The tag-and-attribute contract lives in `Config.Shop` in `src/shared/Config.luau`; this document names every part that needs a tag and the value its `ShopZone` attribute must carry.

A tag no service reads is orphaned code. Every tag below is read by `WorkService` at shift start.

## Tag + attribute contract

| Config key | CollectionService tag | Attribute name | Attribute values |
|---|---|---|---|
| `Config.Shop.CounterTag` | `AgesShopCounter` | `ShopZone` | `"counter"` |
| `Config.Shop.ShelfTag` | `AgesShopShelf` | `ShopZone` | `"shelf_food"`, `"shelf_chilled"` |
| `Config.Shop.CrateTag` | `AgesShopCrate` | `ShopZone` | `"crate"` |
| `Config.Shop.ChillerTag` | `AgesShopChiller` | `ShopZone` | `"chiller"` |
| `Config.Shop.QueueTag` | `AgesShopQueue` | `ShopZone` | `"queue"` |

## Parts to tag

All coordinates are the ones already authored in `gen_town.py`. Only the tag and attribute are new.

### Counter (tag `AgesShopCounter`, zone `"counter"`)

Tag **both** of these — the service reads the tag group, not individual parts:

- `CounterBase` — the waist-high counter face the player stands behind
- `Till` — the steel till on top of the counter (customer-facing side)

```python
for _part in ("CounterBase", "Till"):
    part = ...  # the existing part
    part:SetAttribute("ShopZone", "counter")
    CollectionService:AddTag(part, "AgesShopCounter")
```

### Shelf faces (tag `AgesShopShelf`, zones `"shelf_food"` / `"shelf_chilled"`)

The two aisle runs each have two shelf faces (north and south sides). Tag every shelf face:

- `AisleSouth` — the south aisle gondola. Zone: `"shelf_food"`.
- `AisleCentre` — the centre aisle gondola. Zone: `"shelf_food"`.
- `Chiller` — the cold-storage unit at the far end of the south aisle. Zone: `"shelf_chilled"`.
- `ChillerGlass` — the glass front of the chiller. Zone: `"shelf_chilled"` (tags the same zone as the frame).

```python
# Food shelves
for name in ("AisleSouth", "AisleCentre"):
    part = ...
    part:SetAttribute("ShopZone", "shelf_food")
    CollectionService:AddTag(part, "AgesShopShelf")

# Chilled shelves
for name in ("Chiller", "ChillerGlass"):
    part = ...
    part:SetAttribute("ShopZone", "shelf_chilled")
    CollectionService:AddTag(part, "AgesShopShelf")
```

### Crates (tag `AgesShopCrate`, zone `"crate"`)

The four stock crates in the bay, and the flat crate-top that caps them:

- `Crate1`, `Crate2`, `Crate3`, `Crate4` — the four upright crates
- `CrateTop` — the flat top that bridges them (also tagged so the service can find the stock mass as a whole)

```python
for name in ("Crate1", "Crate2", "Crate3", "Crate4", "CrateTop"):
    part = ...
    part:SetAttribute("ShopZone", "crate")
    CollectionService:AddTag(part, "AgesShopCrate")
```

### Chiller (tag `AgesShopChiller`, zone `"chiller"`)

- `Chiller` — the metal frame. Zone: `"chiller"`.
- `ChillerGlass` — the glass front. Zone: `"chiller"` (same zone as the frame; the service reads either one).

```python
for name in ("Chiller", "ChillerGlass"):
    part = ...
    part:SetAttribute("ShopZone", "chiller")
    CollectionService:AddTag(part, "AgesShopChiller")
```

### Queue positions (tag `AgesShopQueue`, zone `"queue"`)

The service needs to know where the customer queue stands. Tag the floor area in front of the counter where up to three customers line up:

- The floor tiles or a reference part in the queue lane. The simplest anchor is the **Mat** part (already authored at the entrance, outside the counter zone). Zone: `"queue"`.
- Optionally also tag any existing floor part that sits directly in front of the till — the service reads whichever it finds first.

```python
part = ...  # Mat or a dedicated queue-floor part
part:SetAttribute("ShopZone", "queue")
CollectionService:AddTag(part, "AgesShopQueue")
```
